# Tags slice 1 (read-only naive CATEGORIES) + RFC 0019 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use eng:subagent-driven-development to implement this plan task-by-task.

**Goal:** caldav CATEGORIES becomes a read-only, multi-valued, groupable
`categories` dimension with naive (exact) semantics, plus the normative
tag-interpreter contract as RFC 0019 and its SDK type/registry with the
naive builtin.

**Architecture:** Per the approved design
(`docs/plans/2026-08-20-tags-design.md`, decisions D1/D2/D5/D6/D7): the
interpreter is a wire-shaped SDK interface with a name registry (naive only
implemented here; dodder-hyphen is slice 3); caldav declares `categories` as
a `FieldTag`, `MultiValued`, Groupable, NOT-Inline, NOT-Writable unified
field naming `naive` as its interpreter; per-node facet values are the raw
tags; grouping rides the EXISTING dimension machinery (`--group-by
categories` → ordinary `## =<tag>` value buckets — the continuation-heading
rendering and tag-TERM grammar are slice 3); moves/edits reject loudly via
the existing Mode-none derivation.

**Tech Stack:** Go (SDK `internal/cutting_garden_plugins` + dagnabit
`pkgs/` facade), caldav plugin, caldav testserver fixtures, bats.

**Rollback:** Purely additive (no existing surface replaced); a
`git revert` of the slice's merge removes the dimension and the SDK type.

### Task 1: RFC 0019 — the tag-interpreter contract

**Files:**
- Create: `docs/rfcs/0019-tag-interpreter-contract.md`

**Steps:**

1. Read, in order: `docs/plans/2026-08-20-tags-design.md` (the whole thing —
   it is the approved grill output this RFC normativizes),
   cutting-garden#231's issue body (via the smith issue-get tool, number
   231), `docs/rfcs/0012-plugin-facet-contract.md` §1–2 (house RFC style),
   and `docs/rfcs/0016-plugin-search-capability.md` (a recent
   capability-contract RFC to mirror structurally). Load the `eng:rfc`
   skill and follow its conventions (normative MUST/SHOULD/MAY, numbered
   sections, front-matter status `proposed`).
2. Author RFC 0019 with these sections (content per design D2/D4/D5/D6 —
   do not re-decide anything; transcribe the decisions with normative
   force):
   - **Abstract + motivation** (#231: semantics vary per user and
     destination; interpretation runs HOST-side over plugin-emitted tag
     values, so data plugins — linked or wire — never implement this).
   - **The contract**: `Normalize(tag) → tag`, `SortKey(tag) → key`,
     `Buckets(tags []string, namespace string) → []Membership` (with
     `Membership{Bucket, Via string}`; empty namespace = whole-dimension,
     each normalized tag its own bucket), `Matches(tags []string, term
     string) → bool`, `Complete(tags []string, op Add|Remove, bucket
     string) → []string`. Pure value types, batch-by-node — MUST remain
     serializable (the wire-readiness clause); callbacks and iterator
     types are forbidden by construction.
   - **The registry**: named interpreters; builtins `naive` (this slice)
     and `dodder-hyphen` (specced here, implemented slice 3). Selection: a
     tag field's `UnifiedField.Interpreter` default, overridden by
     `[tags] interpreter` globally and per-account (D6; config
     implementation is slice 3 — spec it now).
   - **naive semantics** (normative): Normalize/SortKey identity; Buckets
     with a non-empty namespace is a bad request ("naive declares no
     namespaces"); Matches exact; Complete appends/removes the exact
     bucket.
   - **dodder-hyphen semantics** (normative, implemented slice 3):
     hyphen-segment hierarchy; immediate-segment rollup with `Via`
     attribution (design D4's worked example verbatim); bare-term
     transitive matching; Complete at a rollup bucket appends the
     namespace tag (`project-client`), per D9. Mark the
     continuation-heading RENDERING as presentation-layer, outside this
     contract, and PROVISIONAL per the design.
   - **The `_` lift rule** (normative for dodder-hyphen, explicitly
     IMMATURE): leading-`_` whole-tag lift (sort-first +
     identity-transparent); in-word underscores literal; interior-segment
     `_` prefix OUT OF CONTRACT (treated literally in v1). Carry the
     design's hyphence-collision maturation note.
   - **Wire binding — defined, unimplemented**: a `[[tag_interpreters]]`
     stanza (RFC 0013-style launch) carrying this method set; explicitly
     deferred until an external interpreter exists.
   - **Tuning levers** from the design (continuation rendering, `_`-lift
     maturity, batch shapes).
3. `just lint-fmt` (prose files are still traversed for trailing
   whitespace etc.).
4. Commit: `docs(rfc): RFC 0019 — tag-interpreter contract (#231)`.

```go
package cutting_garden_plugins

import (
	"reflect"
	"testing"
)

// The naive interpreter is the exact-match degenerate (RFC 0019): identity
// normalization/sorting, whole-dimension buckets only, exact matching, and
// exact-bucket membership completion.
func TestNaiveTagInterpreter(t *testing.T) {
	ti, ok := LookupTagInterpreter("naive")
	if !ok {
		t.Fatal("naive interpreter not registered")
	}

	if got := ti.Normalize("project-x"); got != "project-x" {
		t.Errorf("Normalize = %q, want identity", got)
	}
	if got := ti.SortKey("_inbox"); got != "_inbox" {
		t.Errorf("SortKey = %q, want identity (naive has no lift)", got)
	}

	tags := []string{"work", "errand"}
	ms, err := ti.Buckets(tags, "")
	if err != nil {
		t.Fatalf("Buckets: %v", err)
	}
	want := []TagMembership{{Bucket: "work", Via: "work"}, {Bucket: "errand", Via: "errand"}}
	if !reflect.DeepEqual(ms, want) {
		t.Errorf("Buckets = %#v, want %#v", ms, want)
	}
	if _, err := ti.Buckets(tags, "project"); err == nil {
		t.Error("naive Buckets with a namespace must be a bad request")
	}

	if !ti.Matches(tags, "work") || ti.Matches(tags, "wor") {
		t.Error("naive Matches must be exact")
	}

	added, err := ti.Complete(tags, TagAdd, "urgent")
	if err != nil {
		t.Fatalf("Complete add: %v", err)
	}
	if !reflect.DeepEqual(added, []string{"work", "errand", "urgent"}) {
		t.Errorf("Complete add = %v", added)
	}
	removed, err := ti.Complete(tags, TagRemove, "work")
	if err != nil {
		t.Fatalf("Complete remove: %v", err)
	}
	if !reflect.DeepEqual(removed, []string{"errand"}) {
		t.Errorf("Complete remove = %v", removed)
	}
}

func TestLookupTagInterpreter_Unknown(t *testing.T) {
	if _, ok := LookupTagInterpreter("bogus"); ok {
		t.Error("unknown interpreter must not resolve")
	}
}
```
